# Переключение языка

Система переключения языка была переделана с ручного обновления UI на подход `recreate window`.

## Раньше

После смены языка приходилось вручную обновлять все тексты:

```cpp
setText(...)
setPlaceholderText(...)
```

## Сейчас

При смене языка:

1. Сохраняется состояние окна
2. Переключается `QTranslator`
3. Старое окно удаляется
4. Создаётся новое окно
5. UI автоматически создаётся на новом языке через `tr()`

# Что изменилось в коде

* `QTranslator` был вынесен из `MainWindow` в `main.cpp`
* Конструктор `MainWindow` теперь принимает `QTranslator*`
* Удалён `changeEvent()`
* Добавлены:

  * `saveWindowState()`
  * `restoreWindowState()`
* При смене языка окно теперь:

  1. сохраняет state
  2. переключает translator
  3. создаёт новое окно
  4. восстанавливает state
  5. удаляет старое окно
* Добавлен `QSignalBlocker` для предотвращения рекурсии
* `delete this` заменён на `deleteLater()`
* Весь UI теперь автоматически пересоздаётся через `buildUi()` и `tr()`
