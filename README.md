# Переключение языка

Система переключения языка была переделана с ручного обновления UI на подход `recreate window`.

## Раньше

После смены языка приходилось вручную обновлять все тексты:

```cpp
setText(...)
setPlaceholderText(...)
```

## Сейчас

При смене языка:

1. Сохраняется состояние окна
2. Переключается `QTranslator`
3. Старое окно удаляется
4. Создаётся новое окно
5. UI автоматически создаётся на новом языке через `tr()`

После замечания архитектура переключения языка была переработана.

## Что изменилось

* Логика пересоздания окна была вынесена из `MainWindow` в `main.cpp`
* `MainWindow` больше не создаёт новое окно самостоятельно
* Окно теперь только отправляет сигнал:

  ```cpp
  emit languageChanged(lang);
  ```
* Управление жизненным циклом окна перенесено в `main.cpp`
* Добавлена функция `createWindow()`, которая:

  1 создаёт окно
  2 подключает сигналы
  3 восстанавливает state
  4 выполняет recreate window при смене языка
* Убрана проблема dangling pointer на старое окно
* Архитектура стала ближе к правильному разделению ответственности:

  * `MainWindow` отвечает только за UI
  * `main.cpp` отвечает за lifecycle окна и translator
